HydroClean — Site do projeto (versão revisada)
================================================

COMO ABRIR
----------
Abra o arquivo "index.html" em qualquer navegador moderno.
Não é necessário instalar nada. Todos os arquivos devem ficar na mesma pasta:

  index.html
  style.css
  script.js
  config.js
  assets/logo.svg
  assets/favicon.svg


O QUE VOCÊ PRECISA EDITAR (arquivo: config.js)
----------------------------------------------
Este é o ÚNICO arquivo que você precisa mexer para atualizar as informações.
Todos os valores marcados como "PLACEHOLDER" são provisórios.

1) CONTATOS  -> objeto "contato"
   - whatsapp: número com DDI+DDD, só dígitos. Ex.: 5551999999999
   - whatsappMensagem: mensagem que aparece pronta ao abrir o WhatsApp.
   - instagram: usuário SEM @. Ex.: hydroclean
   - email: e-mail do projeto.
   - telefone: número para ligação, só dígitos com DDI+DDD.
   - telefoneLabel: como o telefone aparece na tela (só visual).

2) FORMULÁRIO  -> objeto "formulario"
   - destino: "whatsapp" (recomendado) ou "email".
     O formulário NÃO finge enviar. Ele abre o WhatsApp OU o app de e-mail
     com a mensagem montada, e avisa isso ao usuário.

3) SIMULADOR  -> objeto "simulador"
   - litrosPorPessoaDia, fatorUso, margemSeguranca, fatorPrioridade:
     ajuste conforme os dados que o projeto definir. O cálculo é dinâmico.
   - modelos: catálogo. "capacidade" (L/dia) é usada no cálculo.
     As faixas de preço são estimativas de demonstração.

4) RESULTADOS EXPERIMENTAIS  -> objeto "resultados"
   IMPORTANTE: não invente dados.
   Enquanto não houver medição, deixe "antes" e "depois" como null.
   O site mostra automaticamente "Aguardando dados".
   Quando medir, basta preencher os números.


OBSERVAÇÕES DE CONTEÚDO
-----------------------
- A linguagem foi revisada para ser cientificamente responsável: o site NÃO
  afirma que a água se torna própria para consumo humano. Usa termos como
  "potencial para", "proposta de", "objetivo do projeto", "em testes
  experimentais" e "conforme os resultados obtidos".
- Nenhum dado, resultado, contato ou instituição foi inventado.

ACESSIBILIDADE E DESEMPENHO
---------------------------
- Respeita "prefers-reduced-motion": desliga o fundo animado e as microanimações.
- O fundo de microalgas reduz a densidade em celulares e dispositivos mais simples,
  e pausa quando a aba não está visível (economia de bateria).
